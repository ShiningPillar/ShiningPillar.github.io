## 背景
很久之前尝试过用 hexo + Github Pages 搭建自己的博客，之后也没有上传过一篇文章。这次想要从头开始，但是希望能直接上传markdown进行发布、不想在本地进行环境搭建。如此一来，有两种合适的选择：
- 基于 Jekyll 构建的 Github Pages
- 自定义 workflow，使用 Github Actions

由于 Chirpy 这个主题功能丰富、官方 starter 模板直接提供了 Github Actions workflow，因此选择了他。


## 部署
参考官方 [Getting Started][https://chirpy.cotes.page/posts/getting-started/]，只有三步。
1. 登录 GitHub，找到官方提供的[starter][https://github.com/cotes2020/chirpy-starter]仓库
2. 点击 `Use this template` 按钮，选择 `Create a new repository`
3. 使用 `<username>.github.io` 命名新的仓库
创建完成后，等待Actions workflow部署完毕（大概2分钟不到），就可以用 `<username>.github.io` 进行访问了

### 刷新
存在更新配置后，明明Actions中已经重新部署，但是刷新后页面仍然不变（或者只变了一部分）。这是因为Chirpy默认配置中开启了PWA缓存，它会在浏览器中注册一个 Service Worker 并且把页面缓存到本地，因此我们点击任何链接都优先读取本地缓存而不是服务器。

解决方法（Edge）：

1. 按 F12 打开开发者工具
2. 切到 Application 标签
3. 选择左侧 Storage → 在右侧看到 Clear site data，点击 Clear selected
4. 刷新页面
